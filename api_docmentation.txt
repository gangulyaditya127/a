**Base URL:** `http://localhost:8004`
**Content-Type:** `application/json`

* **Endpoint:** `/dqCheck/recommendInvestigationAnalysis`

## 2. Recommend Closing Note

Generates a structured and compliant closing note suitable for XSOAR alert closure based on alert details and the analyst's draft.

* **Endpoint:** `/dqCheck/recommendClosingNote`
* **Method:** `POST`

### Request Input

```json
{
    "sourceBrand": "CrowdstrikeFalcon",
    "closing_note": "False positive, standard logon sequence. Macro was blocked.",
    "Alert_details": {
        "CrowdStrike": {
            "...": " [Same CrowdStrike Payload as Above] "
        }
    }
}

```

### Response Output

```json
{
    "success": true,
    "close_note_recommendation": {
        "Alert": "An Office file containing a macro was detected by the File Analysis ML engine during a standard user logon sequence.",
        "Disposition": "False Positive",
        "Impact": "No security impact. The detected process chain is expected behavior for Windows interactive logon and the macro was successfully blocked.",
        "Actions Taken": "Reviewed process lineage (winlogon.exe -> userinit.exe -> explorer.exe). Validated the macro hash. Confirmed the activity was benign and related to normal system operations.",
        "Closure Justification": "The alert was triggered by a low-confidence ML threshold on a standard Windows process. Analysis confirms no malicious activity or intent. The alert is closed as a False Positive."
    }
```

## 3. Validate Investigation Analysis

Validates an analyst's investigation write-up to ensure it accurately references the alert context and follows expected SOC formatting standards.

* **Endpoint:** `/dqCheck/validateInvestigationAnalysis`
* **Method:** `POST`

### Request Input

```json
{
    "sourceBrand": "CrowdstrikeFalcon",
    "investigation_analysis": "The alert was triggered due to execution of an Excel macro. File hash analysis confirmed malicious behavior.",
    "Alert_details": {
        "CrowdStrike": {
            "...": " [Same CrowdStrike Payload as Above] "
        }
    }
}

```

### Response Output

```json
{
    "classification": "RELEVANT_BUT_FORMAT_INVALID",
    "content_relevant": true,
    "explanation": "The Investigation Analysis references the correct alert context regarding the macro execution. However, it lacks the required structural sections (Investigation Summary, Detection Context, Analysis Performed, Findings, Conclusion).",
    "format_valid": false
}

```

## 4. Validate Closing Note

Evaluates an analyst's closing note to ensure it accurately resolves the alert and uses the proper structural headers.

* **Endpoint:** `/dqCheck/validateClosingNote`
* **Method:** `POST`

### Request Input

```json
{
    "sourceBrand": "CrowdstrikeFalcon",
    "closing_note": "Alert: Suspicious macro execution\nDisposition: False Positive\nImpact: None\nActions Taken: Verified normal logon sequence\nClosure Justification: Expected behavior",
    "Alert_details": {
        "CrowdStrike": {
            "...": " [Same CrowdStrike Payload as Above] "
        }
    }
}

```

### Response Output

```json
{
    "classification": "VALID",
    "content_relevant": true,
    "explanation": "The closing note accurately reflects the alert description regarding the macro execution and process chain. It also correctly utilizes the required structural headers (Alert, Disposition, Impact, Actions Taken, Closure Justification).",
    "format_valid": true
}
```
